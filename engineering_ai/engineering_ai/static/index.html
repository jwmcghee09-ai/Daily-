Fusion 360

Unzip, then in Fusion go to Utilities › Scripts and Add-Ins › + and pick connectors/fusion360/EngineeringAIImport. Run it to import every STEP part.

Fusion 360 package

FreeCAD

Unzip, then in FreeCAD go to Macro › Macros… and run connectors/freecad/ImportProject.FCMacro.

FreeCAD package

SolidWorks

Unzip, then go to Tools › Macro › Run and pick connectors/solidworks/ImportParts.swb. It saves SLDPRT files.

SolidWorks package

PicoGK (LEAP 71)

The voxel kernel behind Noyron. Needs .NET 9 on Windows or an Apple-silicon Mac. Unzip, then run dotnet run in picogk/.

PicoGK project

Onshape (direct upload)

Needs ONSHAPE_ACCESS_KEY / ONSHAPE_SECRET_KEY set where the server runs. IDs are in the document URL: /documents/doc/w/workspace.

AutoCAD, Siemens NX, Inventor and most other CAD programs open the STEP and DXF files in the parts folder directly.
